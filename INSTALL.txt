PURE20 INTERACTIVE SYRINGE CALCULATOR
=====================================

Files included:
- calculator.html
- calculator.js
- INSTALL.txt

What changed:
- Added a visual U-100 syringe to all 3 calculator modes
- In "Units -> amount" the syringe is interactive:
  - drag the slider
  - units field updates automatically
  - results update live
- In "Dose -> units" and "Blend" the syringe updates automatically based on the calculated units
- Mobile navigation fix included in calculator.html

How to use:
1) Replace the existing calculator.html
2) Replace the existing calculator.js
3) Commit/upload both files to the root of your repo
4) Vercel will redeploy automatically

Notes:
- The syringe visual clamps display from 0 to 100 U because it is a U-100 visual scale.
- The warning text still appears if the mathematical result goes over 100 U.

- Formula strip removed from below the calculator.
